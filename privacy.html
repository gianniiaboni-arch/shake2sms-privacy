Shake2SMS — Privacy Policy

Last updated: 09-27-2025

Overview

Shake2SMS is a small utility app that sends an SMS message when the device is shaken in a specific pattern. This privacy policy explains what data the app uses and how it is handled.

Data the app uses

  • Phone number: The app stores a phone number you provide locally on your device (in app preferences) so it can send SMS when the shake pattern is detected.
  • Message text: The message you enter is stored locally so it can be sent as an SMS.

Storage & usage

All data stored by the app (phone number, message text, threshold setting) is stored locally on the device only and is not uploaded or shared with third parties.

Permissions

The app requests the following runtime permissions:

  • Send SMS — used only to send the SMS message you configured.
  • Foreground service — used so the app can run the shake-watching service in the foreground.
